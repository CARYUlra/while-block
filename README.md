# ☕ Exercícios de Estrutura de Repetição com JavaScript

Projeto desenvolvido com foco na prática da estrutura de repetição `do...while` em JavaScript, aplicando lógica de programação, validações, interação com usuário e controle de fluxo.

---

# 📚 Sobre o Projeto

Este repositório contém a resolução de 5 desafios propostos utilizando JavaScript, executados via navegador ou Node.js.

O principal objetivo foi aplicar corretamente o laço `do...while`, garantindo que o bloco de código seja executado pelo menos uma vez antes da validação da condição.

Todos os algoritmos foram testados e versionados utilizando Git e GitHub.

---

- JavaScript
- Node.js
- Visual Studio Code

# 📌 Exercícios Desenvolvidos

## 1️⃣ Validação de Senha

Sistema simples de autenticação onde o usuário deve informar a senha correta para obter acesso.

### Funcionalidades

- Solicita a senha ao usuário
- Continua solicitando enquanto a senha estiver incorreta
- Exibe mensagem de sucesso ao autenticar

### Conceitos Aplicados

- `do...while`
- Validação condicional
- Controle de repetição

---

## 2️⃣ Soma com Confirmação

Programa que recebe números inteiros do usuário e acumula os valores até que ele decida encerrar.

### Funcionalidades

- Entrada contínua de números
- Confirmação para continuar inserindo dados
- Exibição da soma total

### Conceitos Aplicados

- Acumuladores
- Conversão de dados
- Estrutura de repetição

---

## 3️⃣ Jogo de Adivinhação

Mini game onde o usuário deve descobrir um número secreto entre 1 e 10.

### Funcionalidades

- Número secreto pré-definido
- Contador de tentativas
- Feedback ao acertar

### Conceitos Aplicados

- Lógica de comparação
- Contadores
- Interatividade

---

## 4️⃣ Validação de Cadastro

Sistema de cadastro com validação mínima para o nome do produto.

### Funcionalidades

- Solicita o nome do produto
- Valida quantidade mínima de caracteres
- Exibe mensagem de erro caso inválido

### Conceitos Aplicados

- Validação de entrada
- Manipulação de strings
- `do...while`

---

## 5️⃣ Desafio Final — Sistema de Cafeteria ☕

Menu interativo simulando um sistema simples de pedidos em uma cafeteria.

### Cardápio

| Opção | Produto           | Valor    |
| ------ | ----------------- | -------- |
| 1      | Café Expresso     | R$ 5,00  |
| 2      | Cappuccino        | R$ 7,00  |
| 3      | Pão de Queijo     | R$ 4,00  |
| 0      | Finalizar Pedido  | -        |

### Funcionalidades

- Menu interativo
- Soma automática do pedido
- Validação de opções
- Finalização com valor total

### Conceitos Aplicados

- Menus interativos
- Estruturas condicionais
- Acumuladores
- Controle de fluxo
