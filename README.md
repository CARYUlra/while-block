# ☕ Exercícios de Estrutura de Repetição com JavaScript

Projeto desenvolvido com foco na prática da estrutura de repetição `do...while` em JavaScript, aplicando lógica de programação, validações, interação com usuário e controle de fluxo.

## 📚 Sobre o Projeto

Este repositório contém a resolução de 5 desafios propostos utilizando JavaScript, executados via navegador ou Node.js.  

O principal objetivo foi aplicar corretamente o laço `do...while`, garantindo que o bloco de código seja executado pelo menos uma vez antes da validação da condição.

Todos os algoritmos foram testados e versionados utilizando Git e GitHub.
