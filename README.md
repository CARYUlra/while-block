# while-block

Este repositório contém cinco exercícios em JavaScript desenvolvidos para praticar o uso de laços de repetição (`do...while`) e entradas via `prompt`/`alert` no navegador.

## Estrutura do repositório

- `senai512/script.js` - Validação de senha: pede a senha até o usuário acertar e mostra "Acesso Permitido".
- `calculador piorarda/script.js` - Soma com confirmação: acumula números enquanto o usuário digitar "s".
- `pense em um numero/script.js` - Jogo de adivinhação: tenta acertar o número secreto e conta tentativas.
- `regra de 3/script.js` - Validação de cadastro: exige nome de produto com pelo menos 3 caracteres.
- `cafezes/script.js` - Sistema de cafeteria: menu interativo que soma itens até finalizar o pedido.

## Como executar

Abra o arquivo `index.html` correspondente à pasta do exercício em um navegador e siga as instruções exibidas pelos prompts.

> Observação: os scripts foram simplificados para rodar no navegador usando `prompt()` e `alert()`.
